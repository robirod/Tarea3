# Tarea 3

Proyecto de análisis de datos sobre el tratamiento de aguas residuales.

## Contenido del proyecto

- `code/main.py`: carga los datos, realiza el análisis exploratorio, genera archivos CSV y PKL, y construye un dashboard con Plotly.
- `code/functions/functionsUnidad3.py`: funciones auxiliares para importar CSV, crear CSV y guardar archivos PKL.
- `dataSets/`: contiene los archivos de datos usados en el análisis.
- `Tarea3.ipynb`: cuaderno interactivo con el trabajo y visualizaciones del proyecto.

## Datos

Los datos a analizar son:

- `dataset_set_A_aguas_residuales.csv`


## Qué hace el proyecto

- Revisa la calidad de los datos.
- Grafica a través del dashboard exploratorio.
- Genera archivos derivados en formato CSV y PKL.
- Evalúa el cumplimiento de normas y visualiza tendencias por planta.

## Cómo ejecutar

1. Crear y activar el entorno virtual.
2. Instalar las dependencias necesarias.
3. Ejecutar el archivo principal: code/main.py

## Notas
El proyecto utiliza `pandas`, `numpy`, `plotly` y `scipy` para el análisis y la visualización.
